Exercise 4.1 — SVG House and Garden

A hand-built scene demonstrating the core SVG shape primitives.

Shapes Used in This Drawing

  • <rect> — sky, ground, house body, chimney, door, tree trunk, windows
  • <circle> — sun
  • <ellipse> — tree leaves
  • <line> — window cross bars
  • <polygon> — roof
  • <polyline> — fence
  • <path> — walkway
  • <text> — "My House" label
  • <g> with transform — tree grouping; windows also grouped for shared styling
